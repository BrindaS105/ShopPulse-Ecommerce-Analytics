# ShopPulse – E-commerce Product Analytics

## Overview
ShopPulse is a SQL-based product analytics project that analyzes
sample e-commerce sales data to understand revenue, customers,
product performance and monthly sales trends.

## Business Problem
An e-commerce business needs to understand which products and
categories contribute to revenue, how customers purchase and
how sales change over time.

## Objectives
- Analyze overall sales performance
- Calculate total revenue and average order value
- Identify top-selling products
- Compare category performance
- Analyze monthly revenue
- Identify repeat customers

## Dataset
The project uses a sample dataset containing 20 orders from
12 customers across six months.

The dataset is synthetic and is created for demonstration
and learning purposes. It does not represent a real company's
confidential business data.

## Technology
- MySQL 8.0
- SQL
- CSV

## Key Findings
- Total orders: 20
- Unique customers: 12
- Total revenue: ₹23,220
- Average order value: ₹1,161
- Total units sold: 57
- Repeat customers: 6

## How to Run
1. Open MySQL 8.0 Command Line Client.
2. Execute the create_tables.sql script.
3. Execute the insert_data.sql script once.
4. Execute the product_analysis.sql script.
5. Review the query results.

## Product Insights
- Accessories generate the highest category revenue.
- Notebook has the highest unit sales.
- Revenue varies across the six months.
- Repeat customers provide an opportunity for retention initiatives.
